UI reuses QuestionView/RoundRunner/OperandBoard/the walkthrough, generalised.

**Tech Stack:** Expo 57 / RN 0.86, expo-router typed routes, TypeScript 6, Jest 30 + @testing-library/react-native, Maestro.

**Produces:**
- `Operation = 'add' | 'sub' | 'mul' | 'div'`, `OPERATION_SYMBOL.div = '÷'`, `DIVIDE_ESTIMATE_MS = 1500`.
- `StepGroup` gains:
  - `{ kind: 'quotient'; q: number; place: number; lead: number; split: boolean; moves: Move[]; steps: PlacedStep[]; cascades: boolean }`
  - `{ kind: 'subtract'; q: number; y: number; yPlace: number; place: number; moves: Move[]; steps: PlacedStep[]; cascades: boolean }`
- `answerOf` (div: `a / b`), `rodsFor` (div: `2N + 1`), `startOf` (div: `a`), `generateProblems` (div: N-digit q and d, 2–9 for N = 1, `a = q × d`, `b = d`, distinct), `problemTargetMs` (div: moves + `MULTIPLY_RECALL_MS` per subtract group + `DIVIDE_ESTIMATE_MS` per non-zero quotient digit + typing q).
- `Exercise.expectedBeads?: number` — `exerciseForProblem` sets it to `q × 10^(N+1)` for ÷ and leaves it undefined otherwise; `expected` is `answerOf`.

**The steps** (`quotientSteps(problem)`, called from `problemSteps` for `op === 'div'`), with `N = digits`, `q = a / b`:

```ts
let soroban = setValue(emptySoroban(rodsFor(problem)), problem.a)
for (let p = N - 1; p >= 0; p--) {
  const digit = digitAt(q, p)
  const remainder = readValue(soroban) % 10 ** (p + N + 1) // the quotient's digits sit above this
  const head = String(remainder).length - 1 // highest place of the remainder (use an integer method, not log10)
  const lead = Math.floor(remainder / 10 ** Math.max(0, head - N + 1)) // its leading N digits
  const place = p + N + 1
  // 商を立てる: one add atom on the (empty) quotient rod; 0 is not placed.
  // split = the quotient lands two rods left of the remainder's head (割れる).
  groups.push({ kind: 'quotient', q: digit, place, lead, split: place - head === 2, moves, steps, cascades })
  // 引く: for each divisor digit from the highest, subtract q × y as tens then ones digit.
  for (let j = N - 1; j >= 0; j--) {
    const y = digitAt(problem.b, j)
    // tens digit at place p + j + 1, ones digit at place p + j, each via placeMove with atomFor(rodValue, digit, 'sub')
    groups.push({ kind: 'subtract', q: digit, y, yPlace: j, place: p + j, moves, steps, cascades })
  }
}
```

(Write it cleanly, reusing `placeMove`, `atomFor`, `digitAt`, `readRod`. Skip subtract groups entirely when `digit === 0`? No — keep one quotient group for a 0 digit (no moves) and **no subtract groups** for it, since nothing is multiplied.)
