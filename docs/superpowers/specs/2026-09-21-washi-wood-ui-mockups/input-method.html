1 · iOS number pad

The standard system keyboard, kept open for the whole session.

+ Familiar, and the least code to write.
− It takes up 40% of the screen, so the soroban has to shrink. The keyboard's grey clashes with the paper, and the letters under each digit don't belong here. The iPhone number pad has no return key, so you still need a separate button.

2 · Built-in keypad (recommended)

A keypad drawn in the app's own paper-and-ink style. The submit button (こたえる) is one of its keys.

+ The soroban stays full size. The layout never jumps when a keyboard opens. Digits and submit sit together under one thumb, and every key fits the style.
− One more component to build and test, and the session tests have to switch from typing into a text field to pressing keys.

Also worth knowing: in the app as it stands, the answer field isn't focused automatically. The keyboard only appears after you tap an invisible, unstyled field, so the learner has to find it first. Either option fixes that. The reading drill (0–9) and the session (answers up to 18) would share the same input.
